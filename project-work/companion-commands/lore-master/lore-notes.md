## Command Naming: APPROVED

All command names fit Classic-Luclin EQ thematic conventions:

- **!passive / !balanced / !aggressive** — Standard EQ pet stance vocabulary from Classic.
- **!follow / !guard / !recall / !flee** — Standard EQ command vocabulary.
- **!assist / !target** — Standard EQ group vocabulary. `/assist` existed in Classic.
- **!dismiss** — Correct EQ mercenary and pet dismissal language.
- **!hold (new)** — APPROVED. "Hold" is authentic EQ guard/military vocabulary. City guards issue "Hold!" commands. Classic `/pet hold` established this precedent. Behavior (guard + passive) matches what a guard NPC does when ordered to hold a post. Thematically coherent.
- **!buffme / !buffs** — Informal but consistent with practical player-facing vocabulary.

### Non-Blocking Observation: !tome naming

"Tome" in EQ lore refers to bound magical texts and skill books (Tome of the Altar, research tomes, discipline tomes). Using it as a movement/recall command is semantically incongruous. However, this is a pre-existing command name NOT introduced by this PRD. Not a blocking issue; flagged for the record only.
