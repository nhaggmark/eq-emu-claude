### architect → implementation team (infra-expert) — Path 1 primary
- **Date:** 2026-04-20
- **Notes:** Architecture doc complete at `architect/architecture.md`. Root cause:
  `Items:DisableNoDrop` is a shared-memory-snapshot-time rule; the `items.bin` memory-mapped
  file is only regenerated by re-running `./bin/shared_memory`. Zone processes never
  re-read the rule. Runtime NO-TRADE sites and the Titanium client both key on the cached
  `item->NoDrop` byte. Primary fix is operational: stop all EQ server processes, confirm
  `Items:DisableNoDrop=true` in ruleset 1, re-run `./bin/shared_memory`, then restart
  loginserver + world + 8 zones, then player relog. Spawn ONLY `infra-expert` first.
  `c-expert` joins only if Path 1 does not resolve the block (then a 3-file, ~7-line C++
  runtime rule patch in `common/item_instance.cpp`, `common/patches/titanium.cpp`, and
  `zone/client_packet.cpp` is the fallback).
